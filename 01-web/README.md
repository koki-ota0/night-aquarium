## 今回の主な仕様

- 展示は14室です：冷たい海／暖かい海／大型生物の海（冷・暖）／砂浜／サンゴ礁／深海／川／湖／熱帯マングローブ／冷たい河口／ペンギン／アシカ／カワウソ。
- 水槽へは何体でも入れられます。1画面には最大20体を表示し、水槽ごとに複数ページへ振り分けられます（「なかま・配置」→表示ページ）。
- 配置は生息環境に合う水槽だけに限られます。深海の生きものは深海だけ、冷たい海の生きものは暖かい海へは置けません。マグロのように両方に生息する種は両方から選べます。
- 繁殖用水槽を最大5つ作れます。環境を選んで作り、ペアを移すとそこで繁殖します。
- 探索の行き先は外洋・近海・深海・川・湖・河口の6分類です。探索中も「探索ホームに戻る」で行き先一覧へ戻れます。
- 「ふたりのワンシーン」の入口は図鑑だけになりました。図鑑で種を選ぶと説明が見られ、個体のページはそこから別に開けます。
- 旧セーブの個体は、名前や記録を保ったまま、合う展示室へ自動で移ります。

## すぐに遊ぶ

- プレビューを開くか、配布用 `yoru-no-suizokukan.html` をWebGL対応ブラウザで開きます。単体HTMLは画像・3Dコードを内包し、オフラインでも動きます。ソースZIPだけの場合は後述の手順でビルドします。
- **図鑑**：デモでは全277種が公開されています。未獲得は「見本」で、眺めるだけではセーブの発見数に入りません。名前・番号・展示・大きさで検索・絞り込みできます。詳細の「水槽の見本を見る」、または「この見本をお迎え（デモ）」を選べます。お迎えしたときだけ実際の個体になります。
- **水槽**：館内の14展示室から選びます。各水槽の収容数は無制限、表示は1ページ最大20体です。＋／−・ピンチでズームし、ドラッグまたは魚の追跡を選べます。ライトは1タップで切り替わります。
- **名前と配置**：水槽の「仲間」から個体を選び、名前を入力・保存。「水槽をかえる」から解放済みの対応槽へ移動できます。海水・淡水の違いは守り、「大型生物の海」は参考寸法3m以上の海水動物が対象。川と湖の両方で暮らす種も個体ごとに選べます。河口は従来通り対象種が各槽に対応します。空欄で名前を解除でき、種名は別に残ります。
- **表示ページ**：1ページ最大20体で、ページごとに表示する組み合わせを選べます。室の収容数に20体の上限はありません。生息環境と混泳の分類はゲーム表現であり、実際の飼育の適否ではありません。
- **探索**：外洋・近海・深海・川・湖・河口の6方面。初回はクマノミを必ず発見し、次回から選んだ方面の候補から抽選します。デモ探索券は5秒で1枚、最大3枚です。探索中はホームへ戻れます。
- **お世話**：水槽の「ごはん」を開いて餌を選ぶと水面から落ち、食べられる仲間に一時的に寄り、口元で餌が小さくなって泡が出ます。表示ページに対象がいない場合は対象のページへ一時的に移り、演出後に元のページへ戻ります。途中で手動操作した場合は操作を優先します。演出が終われば視点は戻り、途中で手動操作すれば自動カメラは解除されます。OSの「動きを減らす」では自動ズームと泡を省きます。初期選択の「おまかせ」は各個体に合う餌を配ります。槽ごとに給餌対象を分け、同じ室の給餌回数と飾りは共有します。適合する餌、好物、性格、観察ノートは個体詳細にあります。環境種・デモ見本・待機中の仲間は餌の対象外です。
- **栄養キューブ**：探索などで手に入る、ゲーム内のお世話アイテムです。1個で育成度＋10。飾りの解放や2回目以降のお相手の交換にも1個使います。旧版の育成素材の所持数をそのまま引き継ぎます。実際の生物に与える餌ではありません。
- **繁殖**：同種の♂♀を同じ繁殖槽に入れ、育成度や空腹などの条件が揃うと判定します。判定は1回30%、デモでは1分、通常24時間。同種は最大6体です。繁殖槽は最大5つ作れます。性別・繁殖はゲーム用の簡略化です。
- **そのほか**：個体の性格、ゲーム内の共生4組、装飾の配置、おかえり記録を維持しています。季節の取り逃しや連続ログイン強制、病気・死亡の罰はありません。

- 動物231種は、参考寸法で**小型：30cm未満109種／中型：30cm〜1m未満63種／大型：1〜3m未満37種／超大型：3〜8m未満17種／超巨大：8m以上5種**に再分類しました。環境種10は対象外。クロマグロ（参考2.5m）とネコザメ（1m）はともに大型ですが、前者を大きく表示します。シャチ（6m）は超大型、シロナガスクジラ（25m）は超巨大です。

## 大切なセーブデータ

**移行前に、旧画面の「設定 → 現在のセーブを書き出す」でJSONを手元に保存してください。** このデータには個体名・進行記録が含まれ、暗号化されません。ファイルやプレビューURLを第三者に渡さないでください。

- 同じオリジンのWeb 2.4〜2.12のv5セーブは、2.13で個体ID・名前・サイズ・探索や繁殖のタイマー等を保持します。同定できた実在種の旧IDは引き続き展示します。
- 旧4室の淡水・汽水個体は、新しい川と湖／河口へ**表示上のみ**集め、個体の保存済みの部屋と繁殖タイマーを自動では変更しません。旧槽に分かれた繁殖組は統合せず、給餌残数は最少の値を使います。旧槽の飾り位置も保存されますが新室には自動移動しません。旧海水個体は元の室に残し、別のおすすめ室がある場合は任意の移動を提案します。2.12以前の旧大回遊の生き物は当時の冷温帯・暖かい海・引継ぎ展示を維持し、新しい大型槽に勝手には移しません。旧川湖の個体も以前の川側に残ります。明示的に移すまで保存上の室と繁殖タイマーを変えません。旧版の探索途中は広い候補のまま完了し、新しい絞り込み先は途中から付け足しません。手動移動で繁殖の組・判定時刻が変わる場合があります。
- 旧来の創作種や、同じ実在種と断定できない旧個体・未対応IDは、別の種へ勝手に変換せずセーブに保管します。新展示・お世話・新しい図鑑の発見数には入りません。設定の「前版の記録」で保管個体の一覧・件数を確認でき、JSON書き出しにも含まれます。発見記録のみの場合は件数を表示します。
- **別URL・別オリジンのブラウザ保存は直接読めません。** 旧URLでJSONを書き出し、新URLの「設定 → ファイルから読み込む」で内容を確認して移行します。読み込みは現在の進行を置き換えます。直前の状態は設定から1回だけ戻せますが、前後のJSONを両方保管してください。旧URL・JSON・バックアップのいずれにも元データがなければ復元できません。
- `npm start` のプレビューでは、ブラウザ内に加え、このワークスペースの `preview-data/current.json` にも自動バックアップします。同じ保存先に接続でき、新オリジン側にローカル保存がなければ復元できます。端末とバックアップが異なる場合は勝手に上書きせず、両方を保存してから選べます。一般向けクラウド同期ではなく、ワークスペース消失・別ワークスペース移動・書き込み障害を保証しません。
- 単体HTMLや一般的な静的ホスティングでは端末内保存とJSON移行を使います。ブラウザのサイトデータ削除で端末内保存は消えます。読み取れない保存は自動上書きを停止し、可能な場合は元データを保存できます。データが見えないときは初期化せず、旧URL・端末とJSONを確認してください。
- 安全確認の上限はJSONファイル／プレビュー送信5MB・個体4,096体です。通常の獲得上限と前版の個体を合わせても旧1,500体の制限に当たりにくいよう拡張しました。ブラウザの保存容量や端末状況によって、それより前に書き込みが失敗する場合もあります。
- PWA版を更新する場合は、オンラインで開いて再読込してください。初回訪問後のオフライン起動に対応しています。オフラインのままでは古いキャッシュが出ることがあります。
- 旧IDの採否は `data/old-id-audit.json`。元の100項目カタログと旧仕様は `docs/`・`docs/archive/` に参考資料として残し、現行の展示には使いません。

## 制約

探索ジオラマは水槽のWebGL描画器を共有し、表示中は約30fpsを目標に描きます。他画面や非表示では探索側の描画を止め、探索終了時に専用の描画資源を解放します。OSの「動きを減らす」ではジオラマを静止し、残り時間と進捗は更新します。WebGLを使えない場合は静止したボクセル風の代替絵を表示します。性能は端末により異なります。

PC上のPlaywright Chromiumで検証したブラウザ試作です。スマホ実機、全OS／ブラウザ／支援技術、ストア配信、広告、プッシュ通知、一般向けアカウント同期は未検証または未実装。旧Flutter試作にはWeb 2.4以降と今回の200種・動き・探索演出・サイズ分類・保存・給餌演出・6室・探索先の絞り込み・今回の分槽・配置・命名の変更を移植しておらず、Webとは保存領域が別です。iOSアプリのビルドには別途MacとXcodeが必要です。
