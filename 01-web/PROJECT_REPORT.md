# 制作・検証レポート｜よるの水族館 2.3

更新日：2026年10月27日。PM・ゲームデザイン・実装・テストは品質上の観点として扱い、実在のチームや専門家が参加・監修したとは主張しません。

## 2.3の主な改善

1. **進化を理解しやすく**：全56分岐の判定をUIと共通化し、達成済み・未達成のチェックリストと現在値を表示。名前を伏せた新しい姿を条件成立後に発見でき、未達のライト条件がある場合に詳細から1タップで変更できます。従来の条件や親を残す挙動は維持しました。
2. **探す・選ぶ**：図鑑の種類名・個体名・番号検索と、発見状況・進化可能・展示カテゴリを組み合わせた絞り込みを追加。未発見名では検索できません。同種の複数個体は一覧で名前・性別・育成・空腹・水槽を見て選択できます。
3. **任意の次の一歩**：チュートリアル後、進化可能、餌を与えられる空腹の仲間、次の館長賞の順でおすすめを表示。報酬や強制はありません。空腹の案内は該当する水質へ移り、部屋を開くときも仲間がいる水質を優先します。
4. **小画面と入力**：日本語IMEの変換中は自動更新を保留。固定された閉じるバーを用意し、入力欄と重ならないようにしました。個体一覧への戻りとフォーカスを維持します。

## 2.2の主な改善

1. **混合食性のお世話**：1回の給餌で各個体に適合する「おまかせ」を追加。水槽別の上限を維持し、育成＋8、手動の好物＋12としました。対応する餌の粒が上から落ち、表示中の動物が近づきます。
2. **飼育と繁殖の状況**：おなかの低い個体数・個体値、繁殖条件を満たさない理由、現在の空腹、直前の判定結果を表示。空腹の表示は開いたままでも更新します。既存の1回30％、判定間隔、親子・兄弟除外、全展示室合計6匹の上限を維持。
3. **操作性**：詳細シートのスクロール・入力途中の名前・フォーカスを更新時に保持。閉じるボタンの固定、背後の操作抑制、Tab循環・Esc・フォーカス復帰、餌リストの横スクロール位置の保持を追加。制御だけの変更時は3Dモデルを再生成しないよう改善。
4. **セーブの持ち運び**：v5／v4／v3 JSONを検証して読み込み確認後に置き換え、直前の状態を1回だけ復元可能にしました。別オリジン間の移動、壊れたファイル・容量不足時の非破壊を確認。読めない既存データは保存を止め、元の文字列を保存できます。

詳細と判断理由は `CHANGELOG.md`。以前提案した5案の採否は `PLANNING_DECISIONS.md` です。
