# Web 2.27 展示室の景観レビュー

## 白線・白い点の意味と扱い
- 上部の細い共通白線は、水面位置と連動しないCSS装飾でした。全展示室から除去しました。
- 暖かい海・大型暖海の固定点は日差しを示すつもりの装飾でしたが、水中での意味が伝わりにくいため削除しました。冷海の浮いた氷片や光点も、意味が分かりにくいものは整理しました。
- 常時漂う汎用的な泡は展示室では非表示にしました。摂餌時に口元に出る泡は残しています。深海のマリンスノー、川の流れ、水陸展示の実際の水面境界は残しています。

## 端までの景観
14室すべてを390×844のChromium実画面で最小倍率（通常0.8倍、大型海0.4倍）にして確認。各室に合う砂、岩、海藻、サンゴ、葦、根、岸辺、深海の岩などを左右の画面端まで追加しました。大型海は中央の広い遊泳空間を保ちつつ、遠方の海底斜面を外側へ延長。水陸室は左岸の連続性を維持。これはゲーム向けの景観表現です。

## 検証と範囲
- 単体105件、14室の最小倍率・ズーム・ドラッグのブラウザテスト、従来の展示・追跡・種検索・お迎えなどのE2E、互換餌の摂餌・泡、保存バックアップ、バランス検査に成功。
- 過去の `feeding-material.e2e.cjs` は旧配置を前提に不適合な種を砂浜へ置くため現行の自動移行後は成立しません。代わりに現行の適合展示室で摂餌と泡のE2Eを追加して確認しました。
- 既存保存は読み取りのみで検証。種ID・番号、クラゲモデル、獲得個体、保存形式や探索バランスは変更していません。277 / 300種。Flutter・Android/iOS実機は今回対象外です。
