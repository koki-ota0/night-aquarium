# Web 2.21 デザインと図鑑の整理

## 展示室
- マゼランペンギン：南米温帯の海岸を参考に、岩と砂の休息台、巣穴、海への段差。南極の氷を前提にしない。参考：[すみだ水族館・アルゼンチンでの暮らし](https://www.sumida-aquarium.com/column/details/4998.html)、[すみだ水族館・ペンギン](https://www.sumida-aquarium.com/about/floor/penguin/)。
- カリフォルニアアシカ：岩場と浮き桟橋、海藻。自然の岩や人の浮き桟橋を休息場所に使うことを参考にした。参考：[Monterey Bay Aquarium](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/california-sea-lion)。
- コツメカワウソ：浅い淡水域、植生のある川岸、巣穴、根と小石。参考：[Animal Diversity Web](https://animaldiversity.org/accounts/Aonyx_cinerea/)。
各室で水中遊泳から陸上休息へ移る既存アニメーションは維持。景観はゲーム用の抽象表現で、実際の飼育環境を保証しない。

## クラゲ
2.20で追加した7種を、既存クラゲと共通の充実した立体ボクセルの傘と触手を基礎に再設計。放射状の筋、傘の色と高さ、触手・口腕の長さ、サカサクラゲの逆さ姿勢など、種による区別は残す。表示上の単純化があり、細胞・触手数や透明度は実物を厳密再現したものではない。

## 図鑑
既定は来館者に分かりやすい仲間順。魚・哺乳類・鳥類・爬虫類・両生類・クラゲ・サンゴ類・甲殻類・軟体動物・棘皮動物・ホヤ・植物／藻類を大まかに区分し、各区分は分類データの目・科・属を使って整列する。生物の正式な系統樹順そのものではない。GBIFの分類を `data/dex-taxonomy-221.json` に固定して用い、主要な区分は種のモデル形態と照合。クラゲ（刺胞動物）とサンゴ・イソギンチャクは来館者向けに分けている。

**番号は従来のまま**。仲間別表示では番号が飛び飛びになるが、以前の番号による検索や既存記録との対応を維持。旧来の番号順・名前順・発見済み優先も選択可能。種の内部ID・セーブ・個体・発見記録は書き換えない。

## 検証と限界
Node単体93件、既存操作・バックアップE2E、3室とクラゲのお迎えE2E、分類表示・番号検索E2Eを実行。画面確認はChromiumの390×844相当。Android・iOS実機では未検証。図鑑は265種のまま、300種には未到達。
