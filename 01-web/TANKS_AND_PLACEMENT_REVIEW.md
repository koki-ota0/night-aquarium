# 水槽・個体配置の設計判断｜Web 2.13

更新：2026年11月5日（日本時間）。公開資料を参考にしたゲーム設計です。外部専門家の監修ではなく、実際の飼育方法・混泳や動物福祉の保証ではありません。

## 1. 室と槽

従来の6展示室はそのまま、大回遊を**冷たい海・暖かい海・大型生物の海**、川と湖を**川・湖**、河口を**熱帯マングローブ・北の河口**に分けます。砂浜・サンゴ礁・深海の各1槽を足して通常10水景です。必要な旧保存には「引継ぎ展示」も表示します。

- 新規・デモの大回遊32種は、参考寸法3m以上の16種を大型海へ、残りを冷9・暖7に配置。大型海は背景を控えた開放的な景観です。冷暖は**代表的なゲーム展示**であり、排他的な分布・厳密な水温ではありません。例えば[NOAAのクロマグロ](https://www.fisheries.noaa.gov/species/pacific-bluefin-tuna)は温帯から熱帯・冷涼沿岸まで分布し、[ザトウクジラ](https://education.nationalgeographic.org/resource/incredible-journey/)は冷たい摂餌域と暖かい繁殖域を移動します。大型海は温度帯の代替ではなくサイズを見せる展示です。
- 新規・デモの川湖49種は川に40種（うち環境1）、湖に9種を初期配置。川は石・流木・水草、湖は平たい石・葦・浮葉で分け、同じ種を個体ごとにどちらにも移せます。例えば[FishBaseのコイ](https://www.fishbase.se/summary/cyprinus-carpio.html)は川と湖の両方に生息します。ゲームの湖に並ぶ種は特定地域の同一湖の再現ではありません。
- 河口は元の2槽を維持。新規探索は従来の外洋・砂浜・川・湖の4絞り込み候補と、重複を含む従来の出現プールを変更しません。探索先と取得後の展示槽は必ずしも一致しません。

## 2. 配置・待機・保存

- 「仲間」→個体→「水槽をかえる」。解放済みの展示から選択します。海水／淡水／汽水をまたぐ移動はできず、汽水槽は対象種のみ。大型海は海水動物かつ参考寸法3m以上。他の海水室は海水の仲間、川湖は淡水の仲間を対象とする、遊びやすさを優先した簡略化です。冷暖の代表槽を相互に移すこともできます。これは混泳や生息域の適合判定ではありません。
- 各槽は**獲得した動物20体まで**。環境生物・未獲得のデモ見本は数えません。満槽の新規獲得・デモお迎えは個体を失わず待機に保存します。空きのある対応槽へ移すと展示できます。お相手の追加・出産も満槽で止まり、出産タイマーは維持します。従来の同種6体上限に達した発見は従来どおりキューブになります。
- 旧版ですでに20体を超える場合は自動で移動・削除しません。残りが20体未満になるまでその槽への追加を止めます。2.12以前の大回遊の大型生物も以前の冷暖槽に残し、旧川湖の個体は以前の川側に表示します。本人が指定した場合だけ保存上の配置を変えます。旧版の創作個体・未知IDも削除せず記録に保管します。
- 名前は個体単位で保存し、空欄にすると解除します。待機個体には名前と移動を設定できますが、追跡・給餌・繁殖には参加しません。繁殖は同じ保存室・水質・槽のペアが対象。旧来の繁殖タイマーは旧既定槽のまま保ち、本人の手動移動でペア・判定時刻が変わる場合があります。給餌対象は槽別、回数・飾りは室で共有します。
- 保存には `exhibit_section` と `placed` を個体別に追加。旧値のない個体は旧展示槽として解釈し、未知種の安全な槽IDはそのまま保管します。`yoru_aquarium_save_v5` の既存キー・旧schemaは維持。プレビューの個人データは配布物に入れません。移行前のJSON書き出しを推奨します。

## 3. 画面と3D

主操作は水槽内の「ごはん」「仲間」「ほかの操作」にまとめ、餌の種類や繁殖・飾り・サイズ比較は必要なときに開きます。個体の名前・配置は仲間一覧から見つけられます。2.12の大きさ比率と既存のズーム・魚追跡は維持します。

ジンベエザメは汎用サメの流用をやめ、幅広い頭と平らな口、細かな斑点、鰓、2枚の背びれ、非対称尾を持つ専用の**動く3D形状**に変更。目は丸く、白い光を入れました。クジラ、イルカ類、エイも目・顔まわりを調整しています。参考用の生成画像 `assets/large-fish-cuteness-reference.png` はデザイン検討用であり、ゲーム内の静止画像を置き換えたものではありません。形はかわいさを優先したボクセル表現で、解剖学的な厳密再現ではありません。

## 4. 現実の水族館との差

20体はゲームの上限であり、実際には個体ごとの大きさ・行動・水量・水質・水流・隠れ家・捕食関係が重要です。[EAZA動物福祉基準](https://media.eaza.net/uploads/2024_04_WAM_Standards_Approved_06a0df2fe8.pdf)と[Merckの水生動物の環境疾患](https://www.merckvetmanual.com/exotic-and-laboratory-animals/aquatic-systems/environmental-diseases-of-aquatic-animals-in-aquatic-systems)も種・個体に合った環境の重要性を示します。クラゲ専用循環、アザラシの上陸場所や大型生物に必要な実規模設備は未実装です。[水族館構成レビュー](AQUARIUM_REVIEW.md)も参照してください。
