# Web 2.25｜生きものの形と図鑑の整理

- クリオネは淡い体、オレンジ色の内臓と翼を保ち、頭部と翼をやわらかい形に。実際の姿を優先し架空の目は追加していません。ボクセルの不透明な淡色による半透明風の表現です。[ハダカカメガイ](https://kids.yahoo.co.jp/zukan/animal/kind/invertebrate/0012.html)
- ザトウクジラとシロナガスクジラは大きめの瞳・ハイライトと口元を追加。ザトウクジラの長い白い胸びれとシロナガスクジラのすっきりした形は維持。
- コツメカワウソは丸い顔、目と明るい口元・短いひげを調整。アフリカツメガエルは水かきと平たい体を保ちつつ体の断面を丸く。
- ニホンウナギとウツボは9から14の分節に増やし、体を長く、波打つ動きを連続して見えるよう調整。実寸の表示スケールと番号・IDは維持。
- 無脊椎動物は「泳ぐ・歩く仲間」と「岩などに定着する仲間」に分割。後者は成体が通常定着するサンゴ・ホヤ・イガイ・イソギンチャクなど。完全に動かないという意味ではなく、イソギンチャクやイガイは移動でき、幼生は遊泳する種もあります。クラゲは引き続き独立表示、水草・海藻も別表示。区分は表示の便宜であり生物分類ではありません。
- 確認： [Sea anemone の移動](https://oceaninfo.com/animals/sea-anemone/)、[着生生物と幼生](https://biologyinsights.com/what-are-sessile-organisms-and-how-do-they-survive/)。
