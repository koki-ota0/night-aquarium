## 1. プロダクトビジョン & デザインピラー
> **「一日の終わりに、静かな水族館で魚たちと過ごす。」**

| ピラー | 意味 | 設計上の帰結 |
|---|---|---|
| 集める歓び | コレクションが主役 | 図鑑の隙間・影絵・進化分岐 |
| 静かな癒し | ストレスフリー | タスク上限・広告の押し売り禁止・低刺激な演出 |
| ほんのり学び | 生態の豆知識 | 図鑑の1行トリビア（教育アプリ化しない） |
| あなたの水槽 | 軽い自己表現 | 装飾・レイアウトは世界観の範囲で自由 |

**アンチデザイン（やらないこと）**: 時限ミッションの連打 / エネルギー制の中断 / 強制広告 / 有料ガチャ / 経営数値の管理画面 / ランキング競争の煽り

**競合との差別化**: 水族館経営タイクーン（管理疲れ）とガチャ型コレクション（課金圧）の両方をやらない。「癒し × 誠実な収集」を狙う。

## 3. コアループ & メタループ

```
【探索】海へスカウト（時間制・ストック3・寝ている間も進行）
   ↓ 帰館で自動受け取り（おかえり）
【入手】新しい魚・育成素材・飾り（重複は育成素材に変換）
   ↓
【飼育】餌やり（1タップ）＋ 環境づくり（任意）
   ↓ 放置でも育成が進む
【成長・進化】育成度 × 環境（ライト・水草・岩・砂・サンゴ・共生）で分岐
   ↓
【図鑑】影絵が埋まる・トリビア解禁 → 「次は？」 → 探索へ
```

- **デイリーの必須アクションは2つまで**: ①餌やり ②今日の魚。それ以外はすべて任意
- **メタループ（週〜月）**: 季節イベント / 新種配信 / 水槽の景観づくり / 共生の発見 / 図鑑コンプ率

### 3.1 探索（スカウト）仕様
| 項目 | 仕様 |
|---|---|
| 目的地 | 近海（3h）／岩礁（4h）／深海（6h）。出現傾向を表示 |
| ストック | 上限3。1つ/3h で回復（寝ている間も進行） |
| 入手 | 魚・育成素材・飾りのいずれか。**重複魚は「育成度素材」に変換** |
| 初回保証 | 最初の探索は必ず「近海」の種から1匹（改善案2） |
| ガチャ | **存在しない**。出現テーブルは図鑑に公開 |
| 広告 | 「+1（広告）」を静かに1つだけ配置 |

## 5. システム仕様

### 5.1 魚・図鑑（100種）
- **構成**: 環境種10（#1〜10）＋基本種34（#11〜53, 60, ほか）＋進化種56。進化種は進化でのみ入手
- **レア内訳**: コモン20 / レア29 / エピック27 / レジェンダリー18 / ミシック6
- **入手原則**: 時間と条件を満たせば全員が全種に出会える。季節サイクルで限定種は再来
- **レア表示**: 色だけに依存せず、形状（アイコン縁）でも区別（色覚サポート）

詳細な種リストは `fish-catalog-100.md`（v1.1）を正とします。

### 5.2 育成と成長
- **成長段階**: 幼体（育成度0〜39）→ 成体A（40〜99）→ 完全体S（100）。各段階は図鑑に記録
- **餌やり**: 1日2回（広告で+1、上限5回）。餌1回で全魚の育成度+10。24時間放置の罰則なし
- **放置成長**: オフラインでも育成が進む。再開時に一括計算
- **個体値**: サイズ・色味に±15%の揺らぎ（今日の魚・発見魚）

### 5.3 進化（分岐）
- 基本種34のうち **22種が2分岐、12種が1分岐**（計56進化種）
- 条件は **育成度 × 環境**。例:
  | 種 | 分岐先 | 条件（例） |
  |---|---|---|
  | クラゲ | 三日月クラゲ | 夜に飼育・ライト「月」 |
  | クラゲ | 満月クラゲ | 月ライト＋育成14日 |
  | クマノミ | アカネノリクマノミ | アネモネ設置＋共生成立 |
  | クマノミ | ハナダマリクマノミ | サンゴ設置＋育成度S |
- 分岐先は「？」＋ヒントで提示。条件達成で光る（発見主義）

### 5.4 なでる・好感度（改善案4）
- 魚をタップ → ハート・好感度+1（1日10回まで）
- 好感度が高い魚は泳ぎが軽快になる
- 長押し（500ms）で魚カード

### 5.5 図鑑の節目（改善案5）
- 10 / 25 / 50 / 75 / 100種で「館長賞」モーダル
- 報酬: 探索券+1、餌+1（上限を超えない）

### 5.6 共生（相性）
- 特定の組み合わせを同じ水槽に置くと成長ボーナス＋図鑑の「共生」が1つ埋まる
- 例: アカイソギンチャク × クマノミ系（`anemone_clown`）

### 5.7 水槽・レイアウト
- 水槽は最大5槽（順次解放。試作は4室）。1槽＝1つの情景
- 装飾カテゴリ: 背景 / 砂・底床 / 岩・流木 / 水草 / ライト / 小物
- **景観ボーナス**: テーマ（例「夜の岩礁」）で揃えると小さな成長ボーナス。数値の管理画面は出さない

### 5.8 来館者（薄いシステム）
- 水槽に魚がいると来館者が訪れ、「おたのしみ度」（軽い通貨）を置いていく
- 集客・収支・施設管理は**存在しない**

### 5.9 日課・イベント・通知
| 要素 | 頻度 | 内容 |
|---|---|---|
| 餌やり | 1日2回（広告で+1） | 1タップ |
| 今日の魚 | 1日1匹 | 本日の個体。個体値の揺らぎ |
| 季節イベント | 月1 | 新種・限定装飾・館内演出 |
| 夜の水族館 | 週1（金曜夜） | ライトとBGMが特別になる |
| 通知 | 1日1通 | 21〜22時台のみ。煽り禁止 |

### 5.10 解放
| 解放 | 条件 |
|---|---|
| 水槽2〜5 | 図鑑 10 / 30 / 60 / 100 種 |
| 高難度の探索先 | 育成度合計・図鑑コンプ率 |
| 進化用の環境アイテム | 育成度S＋図鑑マイルストーン |

## 7. UX/UI 方針
- **1手タップ主義**: デイリーの主要操作は1タップ。餌やりは確認ダイアログなし
- **暗所配慮**: 夜の利用が多い。低輝度・暖色寄りのダークを既定に（ライト切替あり）
- **情報量**: 表示は3行まで。数値のダッシュボードは作らない
- **アクセシビリティ**: 色覚サポート（レアリティは形状でも区別）、文字サイズ3段階、片手操作、オフラインで遊べる
- **シェア**: 水槽のスクリーンショットを1タップで共有。「シェアしろ」とは煽らない
- **禁止演出**: 画面フラッシュ連打 / 効果音の乱舞 / 「おめでとう!!!」の大文字煽り / 広告誘導の点滅

## 8. アート & 魚デザイン

### 8.1 アート方向性（要確定 — §0.2 A）
| 案 | 状態 | 内容 |
|---|---|---|
| 案B「おしゃれ・フラット」 | 会議で決定（2026-10-19） | 温かいオフホワイト背景、ダスティティール、魚のみ彩度高め。角丸・極細罫線 |
| 参照画像（ボックス風ボクセル） | 試作で採用方向に検討中 | 立方体の魚、輪郭線、大きな目、ネイビーの夜景、金と大理石（イメージ図） |

**判断ポイント**: 会議決定（フラット）と、現在の試作（ボックス風）は別物です。どちらを正とするか、オーナー確認が必要です。

### 8.2 試作版のカラー（v3・イメージ図準拠）
| 名称 | 値 | 用途 |
|---|---|---|
| ネイビー | `#0A1628` | 夜景の背景 |
| 金 | `#C9A86A` | 枠・見出し・CTA |
| 大理石 | `#F4F1EA` | ホールの壁・ラベル |
| ティール | `#5FD3D0` | ガラス水槽の縁 |

### 8.3 フラット案のトークン（会議決定の基準・prototype-spec §8）
`ink #3A4A52` / `bg #F2EBE1` / `surface #E8DCC8` / `primary #4E8391` / `accent #C97B5A` / 魚の彩度 C50〜70%（UI・背景は C30% 以下）

### 8.4 魚デザインの方針
- **目**: 白い大きな目＋黒い瞳＋ハイライト（2×2の白に黒1と白1）
- **頬**: ピンクのぽっちゃり頬（左右2マス）
- **口**: 小さな笑顔（黒1〜2マス）。餌を食べるとき口が開く
- **亀**: 甲羅はドーム状＋六角形の模様、頭は前に大きく、四肢は大きく広げる、尾は小さい
- **体**: 丸みを強める。ヒレは色を分けて形を分かりやすく
- **制作方式（検討中）**:
  1. 手続き生成（コード）: 亀と細部の判読性に限界。試作で確認済み
  2. 画像スプライト（生成画像を透過処理・揺れ＝列ごとのずらし）: 参照画像に近い。`prototype-v3/sprites/`
  3. 立体ボクセル（.vox）: 奥行きと光が出る。粒度が細かいと不気味になりやすく、2セル単位の粗い箱が参照に近い
  4. 外部のローポリアセット: ライセンス・ボックス風との整合が未確認（受領待ち）

### 8.5 演出（案Bの作法）
| 演出 | 仕様 | 時間 |
|---|---|---|
| 図鑑登録 | 影絵→カラーの光のにじみ＋チャイム | 1.5s |
| 進化 | 水泡のカーテン＋スケールポップ | 2.0s |
| 餌やり | 泡が広がり魚が集合。水滴2音 | 1.5s |
| 今日の魚 | カードが静かに開く | 1.0s |
| BGM | 昼（ローファイ）→夕（暖色）→夜（水音）。3秒クロスフェード | — |

## 9. サウンド
- ローファイ＋水の環境音。音量を上げなくても心地よい
- BGMは時間帯で3種（昼/夕/夜）
- 効果音は水滴・泡の質感で統一
- 通知音は選択式（既定は無音寄り）

## 10. テクニカル設計

### 10.1 本番想定のスタック
| 層 | 選定 |
|---|---|
| エンジン | Unity 6 LTS + URP（2Dベース＋水面・ライトのカスタムシェーダ） |
| ライブオプス | PlayFab（クラウドセーブ・リモコン・A/B） |
| 分析 | Firebase Analytics / Remote Config / Crashlytics |
| 広告 | LevelPlay または AdMob（ATT・同意管理・COPPA対応） |
| CI | GameCI（自動ビルド・自動プレイテスト） |

### 10.2 アーキテクチャ原則
- **オフラインファースト**: 進行はローカル完結。クラウドセーブはベストエフォート
- **データ駆動**: 魚・進化・探索テーブル・イベントはJSON＋Remote Config。新魚はアプリ更新なしで追加
- **イベント時刻はサーバ基準**。育成はクライアント計算＋後日監査
- **性能目標**: ミドル機で60fps／水槽内50〜60匹（GPU Instancing）／起動3秒
- **却下**: Cocos Creator（ライブオプス・採用市場）、ネイティブ（表現×コスト）


## 16. 用語集
| 用語 | 定義 |
|---|---|
| 探索（スカウト） | 時間ベースで魚・アイテムを入手する行動。ガチャではない |
