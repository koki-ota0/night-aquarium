# 2.4｜魚の個性・ワンシーン・模様替え・おかえり記録

## 遊び方

- 魚の詳細に「おっとり」「好奇心旺盛」「マイペース」のいずれかと、種類に応じた動きの説明を表示します。同じ個体には同じ性格が割り当てられます。性格は**見た目だけ**で、食性・育成・繁殖・レア度に影響しません。水底の種類は水底で動きます。
- ふれあいによる好感度上昇は従来通り1日10回までですが、上限後も魚をタップして、しぐさを楽しめます。追加の好感度や成長はありません。
- 「ふたりのワンシーン」は既存のゲーム内の共生4組を使用します。同じ展示室・水質で2種が展示されていると、水槽を見ている時に短いシーンが時々起こります。水槽または図鑑の「ふたりのワンシーン」から確認・再生もできます。記録があっても現在の組み合わせが成立していなければ再生できず、再展示が必要です。ゲーム上の演出であり、実際の生態・飼育方法ではありません。
- 水槽の「かざり・配置」→「この水槽の配置を変える」。上から見た図で水草・岩・砂をつまんで移動し、45度ずつ回転できます。リストから対象を選び、矢印ボタンまたはキーボードでも動かせます。重なった飾りはリストから選べます。「ひろびろ」「まとまり」「初期配置」はいつでも使用でき、素材を消費しません。3D水槽の表示に反映されます。
- 飾りの**配置**は展示室と水質ごとに別々です。飾りの**数**は従来と同じく全展示室で共通で、位置・向きは進化・共生・育成には影響しません。
- 3時間以上離れたあとに戻ると、「おかえりの、きろく」を表示します。探索結果・誕生・育成度A/Sへの到達のうち、復帰時に実際に確定した出来事を最大3件表示します。タップで該当する水槽などに移動でき、いつでも閉じられます。出来事がないときは穏やかな挨拶だけです。ログイン報酬やペナルティはありません。

オフライン中にサーバーが処理するわけではなく、再表示時に保存された時刻から計算します。繁殖の留守中判定は従来通り最大7回です。

## バランス

- おなかの減少を、1時間につき **2 → 1** に調整。適合する餌の回復量＋35、給餌回数・成長量・おなか20未満での成長／繁殖休止は維持します。病気や死亡はありません。
- 同じ時刻に適合する餌を1日1回与える単純な例では、初期値70から給餌直前の値が従来は22→9→0、新設定では46→57→68となります。給餌量の上限や水槽ごとの条件は従来通りです。
- 探索の生きもの80％・素材15％・飾り5％はそのまま。生きものの抽選内で未発見種の重みを1.5倍にし、初回クマノミ保証・出現場所・レア度ごとの基本重み・再会の可能性は維持します。図鑑の探索対象は基本種・環境種であり、進化56種は探索対象になりません。探索画面の確率表示も現在の発見状況に合わせて計算します。
- 固定シード3000試行で近海を24回探索する簡易モデルでは、発見した異なる種類数の平均が10.16→11.00でした。初回保証・今日の魚・進化は除いた机上シミュレーションで、実際の結果や必要日数を保証するものではありません。`npm run balance:check` で再計算できます。
- 更新後の旧セーブも、保存されたお世話時刻から新しい減少率で計算します。そのため更新直後のおなかや、未処理の留守中成長が以前より高く算出される場合があります。

## 保存と将来のFlutter移行

既存Webの `yoru_aquarium_save_v5`／schema 3 に、後方互換を意識した任意フィールドとして追加しています。旧セーブにこれらがない場合は空の値で開始し、個体ID・名前・図鑑・進化条件・かざりの数は維持します。現Web版の書き出し・読み込みにも含まれます。

- 性格：個体UIDをFNV-1aの32bit符号なし値にし、3で割った余りから固定。追加セーブは不要です。
- `dex.moments`：実際に水槽で開始したシーンの `{key, at}`。既存の `dex.synergies`（組み合わせ発見）とは別です。
- `tank.layouts`：`展示室:水質` → `飾り種:番号` → `{x, z, rotation}`。xは−5.4〜5.4、zは−2.7〜2.7、回転は45度刻み。省略した項目は初期位置です。表示上の位置であり、`tank.quantities` を変更しません。
- `welcome_back`：帰館時刻・前回時刻・実際に確定した最大3件の項目。閉じると `null` になります。

WebとFlutterは別の保存領域です。**現在のFlutter試作はこの2.4の機能・調整をまだ実装しておらず、2.4セーブの移行も検証していません。** Flutter版を更新する際は、新フィールド・性格の計算・座標系・空腹／探索の新設定・帰館時処理を実装し、読み込み・書き出しと実機表示を改めて検証してください。
