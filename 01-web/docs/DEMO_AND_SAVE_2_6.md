# Web 2.6｜デモ全公開とセーブ保持

更新日：2026年11月3日。Android・iPhone向けFlutter版には未反映です。

## デモで見られるもの

- 「デモ時間」がオンのとき、探索券は**5秒ごとに1枚**、最大3枚まで回復します。探索自体の所要時間は30／45／60秒のままで、スキップできます。繁殖のデモ判定は1分です。デモをオフにすると券の回復は3時間です。
- 「デモ時間」と「デモ全公開」がオンなら、4展示室・探索先4か所と図鑑100項目を公開します。未獲得種は「見本」と明示し、それぞれの展示室と海水／淡水／汽水に表示します。動物は最大12体ずつページ送り。環境種は水底に表示します。
- 見本は一時的な表示データで、`fish_instances`、図鑑の発見数、獲得個体、餌・繁殖・共生判定を変更しません。見本をタップするとリアクションしますが、好感度は増えません。図鑑の見本の詳細から「この見本をお迎え（デモ）」を選ぶと、初めて実際の仲間として追加・保存し、発見記録に加わります。従来の仲間は削除しません。
- 「デモ全公開」をオフにすると見本だけ消え、発見・獲得済みの仲間は残ります。「デモ時間」をオフにしても見本は非表示になり、通常の公開条件と3時間の回復に戻ります。設定の変更は保存されます。

## なぜデータがリセットされたように見えるか

ブラウザのローカル保存は端末・ブラウザ・URLのオリジンごとに別です。更新時にプレビューのURLや環境が変わると、古いURLに保存されたデータを新しいURLから直接読むことはできません。これはブラウザの安全上の制限です。**既に別URLにしか残っていない旧データは、自動では取得できません。**

## このプレビューの新しい保存先

`npm start` で起動するプレビューでは、端末内の自動保存に加えて、このプロジェクトのワークスペース内 `preview-data/current.json` にも自動保存します。旧URLと新URLが**同じ保存先のワークスペース**に接続できるときは、新しいURLで端末内の保存がなければワークスペースの保存を自動復元します。

- 自動保存の成功・未接続・確認待ちはタイトルと設定に表示します。初回にサーバーの保存を確認してから開始し、異なるデータを上書きしないようにします。
- 端末とワークスペースの両方に異なるセーブがある場合、**自動でどちらも上書きせず**、内容と仲間数を表示して選んでもらいます。両方ともJSONとして書き出せます。プレビュー保管分を選んだ場合は、直前の端末データを設定から1回だけ戻せます。
- 更新はリビジョンで照合し、別画面で先に更新されていれば上書きを止めます。サーバー側にも直前の1件 `previous.json` を保持しますが、その後の保存によって更新されるため、長期バックアップの代わりにはなりません。不正または読めない元データは自動上書きしません。
- プレビュー用サーバーのみの機能であり、アカウント付きのクラウドサービスではありません。**会話のワークスペースが消えた場合や別のワークスペースへ移る場合、保存を保証できません。** 保存済みデータは暗号化されず、プレビューにアクセスできる人が見られます。共有URLや保存ファイルは第三者に渡さないでください。
- `preview-data` は公開用ファイル一覧および配布ZIPから除外します。サービスワーカーはバックアップAPIをキャッシュしません。保存はゲーム操作の後に短くまとめて送信するため、バックアップ完了表示を確認してから閉じてください。通信不可時は端末のローカル保存を使い、オンライン復帰時に再確認します。

## 旧データの取り戻し方と安全な移行

1. 以前のURLがまだ開き、そこに仲間が残っている場合、**旧画面の「設定」→「現在のセーブを書き出す」**でJSONを保存します。
2. 新しい画面の「設定」→「ファイルから読み込む」でそのJSONを選び、内容を確認して読み込みます。既存の進行と置き換えるため、必要なら両方を先に書き出してください。
3. 旧URLも保存JSONもなく、ワークスペース側にも旧データがない場合、失われた個体・名前をこのアプリから復元する方法はありません。
4. 更新前後や別の端末への移動前には、設定からJSONを手元へ書き出してください。ダウンロードした単体HTMLや通常の静的ホスティングには、プレビュー用サーバーの自動バックアップはありません。

## 検証範囲

- Nodeテストは、5秒の境界、100種類・4水槽・水質、見本の非破壊、任意のお迎え、オフライン時の競合と同時更新を検証。
- Playwrightで、実際の旧Web 2.5 HTML／Service Worker v8から2.6／v9へ更新し、ニックネーム・UID・図鑑・配置を保持。その後、同じ保存先の別オリジンへ自動復元し、オフライン再読込まで確認。
- ブラウザ上で別保存の競合、両方の書き出し、選択・直前の復元、サーバープロセス再起動、旧リビジョン・不正・破損データ保護を検証。端末・ブラウザ・サーバーが同じであってもストレージ削除や障害は起こり得ます。
- Android／iPhone実機、Arena環境におけるターンをまたいだ保存の永続性、全ての支援技術・ブラウザは未検証です。
