# Web 2.10｜確認記録と制約

確認日：2026年11月3日（日本時間）。PCのPlaywright Chromium・ソフトウェアWebGLとNode.jsで実施。ブラウザ試験は隔離された一時サーバー・独立したテストデータを使い、通常プレビューの個人保存は操作していません。前版の記録は `docs/archive/VERIFICATION_2_9.md`。

## 今回のデザインと範囲

- 近海・淡水・岩礁・深海それぞれの地形、色、魚種と、ボクセルの潜水艇・海藻・水草・サンゴ・泡を3Dで作成。風景に出る動物は実在カタログの既存3Dモデルを再利用しますが、探索報酬の予告ではありません。実寸や動物の生態の厳密な再現ではないゲーム演出です。
- セーブ済み開始／終了時刻から従来の出発・探索・帰り道を算出し、潜水艇は進路に沿って動き、帰りに方向を変えます。プロペラ、群れ、ひれ、立方体の泡、水草と視点を穏やかに動かします。探索演出はゲーム状態を読み取るだけで変更しません。
- 水槽と1つのWebGLキャンバス・レンダラーを共有。探索を離れたときやページ非表示時に探索側のアニメーションを停止し、探索終了時に専用の描画資源を解放します。省動作設定では絵を静止しながら進捗・残り時間を更新。WebGL不可時は静止したボクセル風SVGへ切り替えます。
- 探索時間・探索券・確率・報酬・セーブ形式、200種・サイズ・給餌・繁殖・ライトは変更していません。デモ探索は30／45／60秒、探索券は5秒ごとに回復。文字だけの観察機能も復活していません。

## 実行した確認

- `npm run build`：単体HTML・PWA用HTML・200種ギャラリーと資料を生成。
- `npm test`：**53/53成功**。4地点の演出用動物が各探索先の実在カタログに存在すること、進路の連続性と帰路、動きを減らす設定、表示がセーブを変えないことを追加検証。
- `npm run test:e2e`：4地点の3Dキャンバスの実ピクセルと外観を確認し、潜水艇・プロペラ・群れの移動、保存タイマーに伴う段階・反転、ARIA進捗、初回クマノミ・自然完了1回・デモスキップ、画面移動／再読込、単体HTMLのオフライン起動を確認。水槽の同一キャンバスが再利用され、往復では再構築せず、終了後に専用のジオメトリが減ることを確認。
- 同E2Eで320px・大きな文字・デスクトップ、OSの省動作の切り替え、ページ非表示からの復帰、WebGLを無効にしたときの代替絵と報酬を確認。実スクリーンショットも目視。200種・大きさ・餌・給餌演出・追跡・ライト・繁殖・栄養キューブの既存回帰試験も成功。
- `npm run test:backup`：隔離データで再起動・競合・破損保護・1,500超の旧個体を検証。
- `OLD_ROOT=... npm run test:upgrade`：実際の2.4〜2.9配布物からSW v13へ更新。2.9からの個体ID・名前・成長・食事記録、キューブ13個、未読報酬、保管個体、探索途中タイマーとオフラインを確認。別オリジンへのJSON移行も実施。
- `npm run balance:check`：既存の探索・空腹シミュレーションは前版と同結果。演出による確率や報酬の変更はありません。
- 配布用ソースZIPを別フォルダに展開し、依存導入・ビルド・53件の単体試験・全ブラウザ／保存／実2.4〜2.9更新／バランス試験を再実行。再生成した2つのHTML、bundle、ギャラリー、調査・餌資料は作業版と一致しました。この項目の追記後、文書のみ更新して再梱包しています。

## 制約

PlaywrightのPCブラウザ・ソフトウェアWebGLでの確認であり、Android／iPhone実機、全OS・ブラウザ・支援技術、長時間の電池消費やフレームレートは未検証です。WebGLがない場合は静止絵となり、通常の3Dジオラマは表示できません。

同じオリジンの更新時の保持を隔離試験で確認しましたが、異なるURL・端末の旧ブラウザ保存は直接読めません。更新前に旧画面からJSONを書き出し、新画面で読み込んでください。バックアップのない消失データを復元できる保証はありません。Flutter版には今回の変更を移植しておらず、Webと保存領域も別です。
