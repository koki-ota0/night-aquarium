# Web 2.12｜確認記録と制約

確認日：2026年11月3日（日本時間）。Node.js 20、PCのPlaywright Chromium、ソフトウェアWebGLを使用。ブラウザ試験は隔離した一時サーバー、独立したデータディレクトリ、または単体HTMLで実行し、通常プレビューの個人保存を試験で上書きしていません。前版は `docs/archive/VERIFICATION_2_11.md`。

## 今回の対象

- 水槽から6室へ直接切り替え、未解放室の制限・選択槽のセッション記憶・獲得した個体の優先表示を確認。大回遊の冷温帯18種と暖かい海14種はそれぞれ別の画面に重複なく表示し、旧個体は仮の配置から見られます。給餌対象・景観は別で、給餌回数と飾りは室単位で共有します。
- 近海の外洋32・砂浜沿岸28、淡水の川16・湖池14の候補・確率・実際の抽選と異なる3D風景、淡水の候補重複、おまかせ51種・60種の維持、初回クマノミ保証と旧探索中データの広い候補での継続を確認。出現する背景の生き物は抽選結果の予告ではありません。
- 沿岸クラゲ3種とアザラシの新規・見本に対する推奨室だけを変更。保存個体は移動しません。クラゲ専用槽やアザラシの上陸場所は未実装です。判断の根拠と未実装項目は `OPEN_SEA_AND_SPOTS_REVIEW.md` と `AQUARIUM_REVIEW.md`。

## 配布物の取り扱い

プレイ用ZIPの単体HTMLはWebGL対応ブラウザでオフライン起動できます。ソースZIPは `npm ci`・`npm run build` で生成し、同じテストを実行できます。旧版を使う試験には別途2.4〜2.11のファイルが必要です。個人の `preview-data/`、依存フォルダ、キャッシュは配布ZIPに含めません。再現手順は `README.md`。

## 制約

PCのPlaywright Chromium・ソフトウェアWebGLでの確認であり、Android／iPhone実機、全OS・ブラウザ・支援技術、長時間の電池消費・フレームレートは未検証です。WebGLが使えない場合は静止した代替絵になります。自然分布・適正水温・混泳・動物福祉の再現や専門家監修は保証していません。温度帯の区分は代表的なゲーム風景で、排他的な生息域ではありません。

同一オリジンの更新を隔離試験で確認しましたが、異なるURL・端末の旧ブラウザ保存は直接読めません。更新前に旧画面の設定からJSONを書き出し、必要なら新画面で読み込んでください。バックアップのない消失データの復元は保証できません。Flutter版にはWeb 2.4以降と今回の変更を移植しておらず、Webと保存領域も別です。
