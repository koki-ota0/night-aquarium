# Web 2.8｜確認記録と限界

確認日：2026年11月3日（日本時間）。テストはPC上のPlaywright Chromium・ソフトウェアWebGLとNode.jsで実施。画面・移行試験は専用の一時サーバー／一時データを使い、通常プレビューの `preview-data/` は操作していません。Web 2.7の検証記録は `docs/archive/VERIFICATION_2_7.md` に保存しています。

## 今回の内容

- 動物190種の参考寸法をもとに、小型93・中型45・大型32・超大型15・超巨大5の5区分に再分類。環境種10は対象外。32種の区分が旧版から変わりました。
- 参考寸法と見た目の関係は、区分別の固定値ではなく、3cm／30cm／1m／3m／8m／25mの表示長を基準とする対数補間です。大きくなるほど表示長も連続して増加します。参考寸法の比率をそのまま再現するものではありません。
- 比較例：ネコザメ1m→表示基準長1.55、クロマグロ2.5m→3.05、シャチ6m→4.87、シロナガスクジラ25m→7.25。個体差、混雑、奥行き、姿勢・向きで画面上の幅は異なります。
- 代表寸法・最大寸法や、体長・甲長・体盤幅・傘径・脚幅・腕を含む全長が混在し、異なる部位を厳密に比較するものではありません。資料や例外は `SPECIES_REVIEW.md` と `data/size-reference-review-2026-11-03.json` に記録。外部の生物専門家による監修はありません。
- 探索の背景・潜水艇・魚影・泡と3段階の進行表示を追加。進行度は保存済みの開始・終了時刻から算出し、観察メモは表示だけで、保存・報酬・抽選を変更しません。

## 配布と制約

単体HTMLには画像・3Dコード・4つの探索背景が埋め込まれています。PWAを更新する際はオンラインで開いて再読込してください。別オリジンの旧ブラウザ保存は直接読めず、旧画面でJSONを書き出して新画面に読み込む必要があります。大切なデータは更新前にJSONで保存してください。

クジラの投影境界は390px・6時点・特定の個体構成で確認したもので、あらゆる端末・混雑・拡大率・個体の完全な非重複や常時表示を保証するものではありません。水槽で見える大きさは実寸比ではありません。

スマホ実機、全OS・ブラウザ・支援技術、長時間の性能、実際の水族館での飼育は未検証。Flutter版にはWeb 2.4以降と今回の2.8変更を移植しておらず、WebとFlutterの保存領域は別です。ワークスペースの保存はクラウド同期ではなく、端末・オリジン・環境による制限があります。
