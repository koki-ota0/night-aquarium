## カタログと造形

- 200学名が保存済みGBIF照合結果で `EXACT / ACCEPTED / SPECIES`。種別の参考資料と生成元の一覧は `SPECIES_REVIEW.md`。学名の照合は、和名や生態・大きさ・形状まで完全に正しいという意味ではありません。
- 200種それぞれで3Dモデルを生成し、有限かつゼロでない境界と、IDに対応する200個の異なるサムネイルを検査。全種のサムネイル一覧を目視し、クジラ、オサガメ、ヒトデ類、エビ、プレコ類などの特徴を追加・調整しました。低解像度のデフォルメであり、近縁種は部品を共有しています。
- マグロの速い遊泳、オオセの水底での静止、クラゲ・イカの動き、ウミウシの底生移動などをプロファイルに割当。全200種について有限値・連続性を検査。実ブラウザでもマグロの移動、オオセの静止、底生の位置と給餌中の動きを確認。科学的な実測速度や全個体の野生行動の再現ではありません。
- 画面上のサイズが小型→中型→大型→超大型の順に分かれることを検査。実寸比ではありません。
