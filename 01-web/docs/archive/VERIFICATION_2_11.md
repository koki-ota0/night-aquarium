# Web 2.11｜確認記録と制約

確認日：2026年11月3日（日本時間）。Node.js 20・PCのPlaywright Chromium・ソフトウェアWebGLで実施。ブラウザ試験は隔離した一時サーバーまたは単体HTMLと専用データを使い、通常プレビューの個人保存を試験で上書きしていません。前版は `docs/archive/VERIFICATION_2_10.md`。

## 今回の対象

- 大回遊・砂浜・サンゴ礁・深海は海水、川と湖は淡水、河口は汽水の6室。水質切替タブはなく、河口室のみ熱帯マングローブ／北の河口の2つの槽を切り替え。底質・色・背景・見本の構成を区別しました。
- 水槽の3D・図鑑・個体詳細・おすすめ展示への導線を改修。展示される200種は維持し、テッポウウオの非保存見本コピー2体を熱帯槽に追加。冷温帯のヌマガレイの上面が見えるよう傾きを調整し、水底近くに保ちます。大きな動物が多い外洋では8体ページ、それ以外は12体を上限とします。
- 旧淡水／汽水個体は新室へ表示上だけ投影。元の室、個体ID、保管・繁殖タイマー、旧飾り配置は自動変更しません。旧槽の繁殖組は別のまま、給餌残数は保守的に共有します。旧海水個体は元の室に置き、推奨室への移動を本人が選べます。手動移動で繁殖組・判定時刻が変わる場合があります。
- 科学的な参考と限界、未実装の改善提案は `AQUARIUM_REVIEW.md`。専門家の外部監修はなく、本作は実際の飼育指針ではありません。

## 実行した確認

- `npm run build`：オフライン単体HTML、PWA用HTML・バンドル、200種ギャラリーと資料を生成。
- `npm test`：**59/59成功**。6室と水質、200種の展示ルーティング、旧室の表示投影・複数の繁殖タイマー・旧飾り、2つの汽水槽、給餌残数、別水質への移動拒否、保存の往復などを検証。
- `npm run test:e2e`：既存の200種・大きさ比較・魚の動き・ズーム／追跡・ライト・給餌／繁殖・探索3D・デモ・オフライン回帰に加え、6室の描画と固定水質、図鑑、河口2槽・熱帯群れ・冷温帯の底生表示、見本の非保存、旧個体の提案・手動移動と別水質への移動不可を確認。320px・大きい文字・省動作・WebGL不可時の代替画面も確認。外洋・砂浜・河口を含むスクリーンショットを目視しました。
- `npm run test:backup`：隔離データによるサーバー再起動、競合、破損保護、1,500超の旧個体を確認。
- `OLD_ROOT=... npm run test:upgrade`：実際の2.4〜2.10配布物を使い、Service Worker v7〜v13からv14への更新を確認。特に2.10からの2つの旧繁殖タイマー、元の部屋、個体名・ID、旧飾り、餌、未読報酬、保管、探索中、JSON書き出しとオフラインを維持。別オリジンの2.6からのJSON移行も確認。
- `npm run balance:check`：探索候補の抽選と空腹の既存簡易試算を実行。今回、探索時間・確率・報酬・栄養キューブ費用は変更していません。
- 配布用ソースZIPを別フォルダに展開し、`npm ci`・ビルド・59件の単体テスト・全ブラウザ／旧版更新／保存／バランス試験を再実行しました。生成した単体HTML・PWA用HTML・bundle・200種ギャラリーは作業版と一致。プレイZIPを別に展開し、ネットワークを切って6室と河口2槽を確認しました。検証後はこの記録のみ追記して再梱包しています。

## 配布物の取り扱い

再現手順は `README.md`。プレイ用ZIPの単体HTMLはWebGL対応ブラウザでオフライン起動できます。ソースZIPは `npm ci`・`npm run build` で生成し、同じテストを実行できます。旧バージョンの実ファイルを用いる試験には別途2.4〜2.10が必要です。個人の `preview-data/`、依存フォルダ、キャッシュは配布ZIPに含めません。

## 制約

PCのPlaywright Chromium・ソフトウェアWebGLでの確認であり、Android／iPhone実機、全OS・ブラウザ・支援技術、長時間の電池消費・フレームレートは未検証です。WebGLが使えない場合は静止した代替絵になります。水族館の実際の飼育環境、全種の混泳適合性、温度・水流・動物福祉の再現や専門家監修は保証していません。

同一オリジンの更新を隔離試験で確認しましたが、異なるURL・端末の旧ブラウザ保存は直接読めません。更新前に旧画面の設定からJSONを書き出し、必要なら新画面で読み込んでください。バックアップのない消失データを復元できる保証はありません。Flutter版にはWeb 2.4以降と今回の変更を移植しておらず、Webと保存領域も別です。
